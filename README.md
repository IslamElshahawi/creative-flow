# Creative Flow Lite

Free, portable skills for writing Arabic video ads that land with a Saudi audience.
Works in Claude Code, Cursor, Codex, Windsurf, OpenCode, and any harness that loads `SKILL.md`.

| Skill | Use it when |
|---|---|
| `saudi-culture` | Casting, styling, staging, or setting a scene for a Saudi viewer |
| `arabic-ad-copy` | Writing Arabic hooks, scripts, captions, or CTAs in Saudi/Khaleeji dialect |
| `hooks-and-ctas` | A hook or CTA is flat and needs a real persuasion mechanism and TikTok format |

## Install

Claude Code:

```text
/plugin marketplace add IslamElshahawi/creative-flow
/plugin install creative-flow-lite@creative-flow
```

Other harnesses: copy the folders in `skills/` into your agent's skills directory.
