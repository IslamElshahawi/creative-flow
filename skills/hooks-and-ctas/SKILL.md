# Hooks and CTAs that convert

Read only the job, the assigned hook family/angle (from `campaign-strategy`'s creative-matrix row), and
the brand claims it must trace to.

## Contract

- Run every candidate line through one test: does it **state a fact or issue an order**, or does it
  **create identification, desire, or a stake the viewer feels**? A line can be factually true and still
  flat. Flat lines are not wrong, they're unfinished — the fact still needs a reason the viewer should
  care, felt rather than told.
- Name the emotional mechanism a hook or CTA is using. Don't write "an attention-grabbing hook" — write
  which of: **aspiration/identity** (this is who I want to be), **self-recognition** (this is my exact
  problem), **relief from a named friction** (the specific annoyance goes away), **social proof**
  (people like me already chose this), **curiosity gap** (an open loop the brain wants closed), or
  **possibility-framed urgency** (what becomes available, not what is threatened). A hook with no named
  mechanism is a guess, not a decision.
- **Cap urgency at possibility, never threat.** "احجزي الحين والا بتندمين" (book now or you'll regret it)
  is a threat-framed command; "اكتشفي ليش البنات كلهم يلبسونه" (discover why every girl is wearing it) is
  the same urgency reframed as an invitation. `saudi-culture` documents that Saudi advertising favors
  warmth and indirect persuasion over US-style hard-sell pressure — treat that as a hard constraint on
  intensity, not a suggestion.
- **Escalate across the script, don't flatline.** A 3-beat script (hook / build / payoff) should feel
  the stakes rise beat to beat — the same emotional temperature in beat 1 and beat 3 reads as one long
  hook that never lands anywhere.
- **This skill owns the why, not the words.** Output an emotional-shape sketch — named mechanism +
  neutral or bilingual gloss of what the line should make the viewer feel — for `arabic-ad-copy` to
  render into locked-register Arabic. Do not hand off finished Arabic copy; that duplicates
  `arabic-ad-copy`'s job and risks drifting off its register lock.
- **Grammar note that's easy to miss when reusing a male-default example**: an Arabic imperative or
  direct-address line changes form when the speaker or intended viewer is female (جرّبي / اكتشفي /
  جربيه, feminine suffix) versus male (جرّب / اكتشف / جربه). Flag this explicitly to `arabic-ad-copy`
  whenever the assigned register/voice is female — it's a grammar concern for that skill to resolve, not
  this one, but it's the single easiest thing to carry over wrong from an existing masculine-voice script.
- Every claim a hook implies still has to trace to `brand-context.md` — an emotionally activating line
  built on an unsupported claim is a `ksa-compliance` failure, not a copywriting win.
- **Use a named viral TikTok format, not a generic "hook."** A mechanism (above) says *why* a line should
  work; a format (`references/full-guide.md`'s format table — POV, before/after, mistake call-out,
  curiosity-gap opener, GRWM, storytime, etc.) says *what shape it takes on this specific platform*.
  `before/after` is the single strongest-performing format in Saudi TikTok data specifically — reach for
  it before assuming a different format is needed. Formats borrowed from English-language TikTok research
  still get written in White Saudi from the first draft, never translated, per `arabic-ad-copy`'s own
  rule — the format is platform-native, the words still have to be register-native.

Read `references/full-guide.md` only for the persuasion-mechanism catalog, the viral TikTok hook-format
library (Saudi-calibrated), worked before/after rewrites, the CTA-specific invitation-vs-command guidance,
and sources.
