# Arabic ad copy

Read only the job, brand context, approved route ID, referenced insight IDs, and current
compliance flags.

## Contract

- Write in Arabic from the first draft; never translate finished English copy.
- Lock one register for the campaign and record it in `campaign.json`.
- Put the hook inside the first 1.5 seconds.
- Keep on-screen lines short enough for 9:16 safe areas.
- Trace every factual claim to brand context; flag unsupported claims.
- Hand off on-screen Arabic as selectable text for post-production.
- Do not ask an image model to render on-screen Arabic.
- Keep copy and shot-list IDs synchronized.

Default register: light Saudi/Khaleeji for consumer lifestyle; use MSA for institutional,
regulated, formal luxury, or broad mixed audiences. Treat this as a starting heuristic,
not native validation.

Read `references/full-guide.md` only for dialect contrasts, hook/CTA banks, numeral
choices, corpus research, claim language, or native-review questions.
